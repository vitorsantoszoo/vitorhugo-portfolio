# 🗂️ Arquitetura e Governança de Dados

Esta disciplina faz parte da **Pós-Graduação em Inteligência Artificial e Aprendizagem de Máquina** e abordou os fundamentos de planejamento, organização, controle e gestão estratégica de dados dentro de uma empresa — desde os conceitos de arquitetura de armazenamento até políticas de governança, qualidade e conformidade.

---

## 🧠 Conteúdo estudado — Arquitetura de Dados

- Conceito de arquitetura de dados em organizações
- Modelos de arquitetura: centralizada, distribuída, híbrida
- Armazenamento e processamento de dados
- Tipos de bancos de dados (relacionais e não relacionais)
- Data Warehouse, Data Lake e Data Mart
- Big Data e Hadoop
- Pipeline de ingestão e transformação de dados
- Papel do Arquiteto de Dados na empresa
- Ecossistemas modernos para processamento massivo

## 🧠 Conteúdo estudado — Governança de Dados

- Conceito de governança e gestão de ciclo de vida dos dados
- Segurança da Informação aplicada a dados corporativos
- Classificação e categorização de dados
- Políticas internas, compliance e LGPD
- Atributos de qualidade (accuracy, completeness, consistency, timeliness)
- Papel e responsabilidades do Data Steward
- Data Catalog e metadados
- Monitoramento e auditoria
- Dicionário de dados
- Políticas de acesso e controles
