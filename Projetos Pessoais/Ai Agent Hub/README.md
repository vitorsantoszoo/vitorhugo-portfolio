# 🤖 AI Agent Hub

**AI Agent Hub** é um projeto modular de Inteligência Artificial integrando **Visão Computacional**, **NLP** e **Agentes de Decisão**.

Este projeto serve como laboratório experimental para estudar arquitetura de sistemas de IA, MLOps e integração multimodal (imagem + texto).

## 📘 Estrutura de Pastas
- `agents/` → Implementação dos agentes inteligentes (visão, NLP, decisão)
- `pipelines/` → Pré-processamento e treino de modelos
- `mlops/` → Controle de versão e logging
- `app/` → Interface e orquestração
- `data/` → Dados de entrada (imagens e textos)
