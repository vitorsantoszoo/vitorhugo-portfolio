# 🚀 Guia de Início Rápido - CertMind V2

## ⚡ Começando em 3 Passos

### 1️⃣ Instalar e Executar

```bash
# No terminal, navegue até o diretório do projeto
cd /workspace/certmind_v2

# Instale as dependências (já feito)
pip install -r requirements.txt

# Execute a aplicação
streamlit run app_v2.py
```

### 2️⃣ Acesse a Aplicação

- Abra seu navegador em: **http://localhost:8501**
- A aplicação abrirá automaticamente

### 3️⃣ Comece a Estudar!

- Escolha entre **Core 1** ou **Core 2**
- O sistema selecionará as melhores questões para você
- Responda e receba feedback detalhado

1. **Estude consistentemente**

2. **Confie no algoritmo**

## 📊 Entendendo as Métricas

### Taxa de Acerto
- **80%+**: Excelente! Continue assim
- **70-80%**: Bom desempenho
- **60-70%**: Regular, precisa revisar mais
- **<60%**: Foque nos fundamentos

### Nível de Domínio
- **0-40%**: Iniciante - continue praticando
- **40-70%**: Intermediário - no caminho certo
- **70-90%**: Avançado - quase lá!
- **90-100%**: Mestre - conceito dominado! ⭐

### Próxima Revisão
- O sistema calcula automaticamente quando você deve revisar
- Baseado no algoritmo de repetição espaçada (SM-2)
- Quanto melhor seu desempenho, maior o intervalo

## ❓ Perguntas Frequentes

### "Quantas questões devo fazer por dia?"
- **Recomendado**: 10-20 questões
- **Mínimo**: 5 questões
- **Máximo**: Sem limite, mas qualidade > quantidade

### "O que é repetição espaçada?"
- Técnica científica de aprendizado
- Revisa conceitos em intervalos crescentes
- Maximiza retenção de longo prazo
- Usado por estudantes top do mundo

### "Devo estudar todos os dias?"
- **Ideal**: Sim, consistência é chave
- **Realidade**: Pelo menos 4-5 dias por semana
- **Mínimo**: 3 dias por semana para manter progresso

### "Como sei se estou pronto para a prova?"
- **Meta**: 80%+ dos conceitos dominados
- **Taxa de acerto**: 85%+ geral
- **Tempo**: Mínimo 4-6 semanas de estudo

## 🛠️ Solução de Problemas

### Erro ao iniciar:
```bash
# Reinstale as dependências
pip install --upgrade -r requirements.txt
```

### Dados corrompidos:
```bash
# Execute a migração novamente
python data_migration.py
```

### Resetar progresso:
- Vá para Dashboard → Opções Avançadas → Resetar Progresso
- **Atenção**: Esta ação não pode ser desfeita!
