# Lógica de Programação

Esta disciplina introduz os fundamentos da construção de algoritmos, raciocínio lógico e programação estruturada aplicada ao desenvolvimento de programas. Aborda os conceitos essenciais necessários para formular soluções computacionais, interpretar problemas, organizar etapas e representar essas soluções em linguagem de programação (com Python como base prática).

---

## Conteúdos abordados

- Conceito de lógica e raciocínio estruturado
- Algoritmos e etapas de solução
- Tipos de dados (inteiro, real, lógico, caractere)
- Regras de criação de identificadores
- Entrada / Processamento / Saída
- Atribuição de valores
- Operadores e expressões
  - aritméticos
  - relacionais
  - lógicos
- Construção de algoritmos
- Estruturas de decisão (simples, composta, encadeada)
- Estrutura de repetição (FOR)
- Implementação em Python — sintaxe base

---

## Aplicação prática no mercado

Lógica de Programação é a base da computação.

É uma habilidade essencial para qualquer área técnica e está presente em:

- automação de tarefas
- programação de scripts de segurança
- análise de dados e pré-processamento
- escrita de ferramentas utilitárias
- desenvolvimento de software em qualquer linguagem

Neste curso, a prática foi feita com foco em Python, principalmente por sua simplicidade, legibilidade e grande utilização em segurança, automação e análise.

A disciplina de Lógica de Programação fornece a fundação para o desenvolvimento de software e automação.
