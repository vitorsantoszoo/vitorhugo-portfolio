# Sistemas Operacionais

Esta disciplina aborda os conceitos fundamentais de sistemas operacionais, seus componentes, mecanismos internos, gerenciamento de recursos e seu papel como intermediário entre hardware e software.

---

## Conteúdos abordados

- Histórico e conceitos de Sistemas Operacionais
- Tipos de Sistemas Operacionais
- Arquitetura e estrutura de sistemas
- Processos
- Threads
- Escalonamento de CPU
- Deadlock
- Sincronização de processos
- Gerenciamento de memória (alocação, paginação, segmentação, swapping)
- Gerenciamento de armazenamento secundário (HD, trilhas, setores, cilindros)
- Gerenciamento de Entrada/Saída (I/O)
- Segurança de Sistemas Operacionais

---

## Aplicação prática no mercado

Compreender Sistemas Operacionais permite:

- melhor entendimento de como software e hardware interagem
- otimização de consumo de recursos
- maior capacidade de troubleshooting
- compreensão de mecanismos de concorrência
- entendimento de segurança no nível de kernel
- suporte técnico de maior complexidade
- análise de impacto sobre desempenho e gargalos

Este conhecimento está presente em funções como:

- Administração de servidores
- Infraestrutura e operações de TI
- Segurança ofensiva e defensiva
- Automação em ambientes Linux
- Hardening e baseline corporativa

---

## Conceitos-chave desenvolvidos

| Tema | Entendimento gerado |
|------|----------------------|
| Processo / Thread | Execução, concorrência, paralelismo e multitarefa |
| Escalonamento | Algoritmos que definem qual processo usa a CPU |
| Deadlock | Situações de bloqueio entre processos |
| Memória | RAM, cache, segmentação, paginação e swapping |
| I/O | Gerenciamento de periféricos e fluxo de dados |
| Segurança | Papel do SO na proteção de informações |

Nesta disciplina não houve projeto prático formal.

## Conclusão

Esta disciplina fornece a base para entender o funcionamento interno de qualquer computador.

Compreender Sistemas Operacionais é essencial para análise de performance, segurança, programação de baixo nível e suporte técnico de alto nível.
