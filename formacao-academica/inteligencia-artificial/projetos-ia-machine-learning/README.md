# 📚 Projetos de I.A e Machine Learning

Esta pasta reúne o projeto desenvolvido na disciplina **Projetos de Inteligência Artificial e Machine Learning**, cursada durante a Pós-Graduação em Inteligência Artificial e Aprendizado de Máquina (UNINOVE – 2025).

A disciplina teve como foco a aplicação prática — estruturada e orientada — de conceitos de IA para solução de problemas reais, seguindo um modelo acadêmico de projeto com etapas definidas, validação, fundamentação teórica e apresentação final.

---

## 🎯 Objetivo da Disciplina

O objetivo desta disciplina foi orientar os alunos na **estruturação de um projeto completo de IA**, passando por:

- definição clara de problema real
- contextualização social / impacto esperado
- fundamentação teórica
- escolha e justificativa de algoritmos
- construção da proposta de solução
- análise de resultados
- projeção de impacto

---

## 🧠 Projeto Desenvolvido na Disciplina

### 🧠 Sistema de Detecção de Lixo em Tempo Real para Cidades Inteligentes

Projeto acadêmico que propõe um sistema baseado em **Visão Computacional** e **Deep Learning** para identificar resíduos sólidos urbanos a partir de câmeras públicas, contribuindo para políticas de cidades inteligentes.

## Observação

A pasta de cada projeto contém sua documentação e materiais associados.

Este projeto não teve código implementado em aula — ele é um **projeto conceitual** baseado em análise, revisão, modelagem arquitetural e fundamentação teórica.
