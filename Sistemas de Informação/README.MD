# 💻 Bacharelado em Sistemas de Informação

Este repositório reúne projetos, atividades práticas e estudos desenvolvidos
durante minha graduação em **Sistemas de Informação**.

O objetivo é documentar minha evolução técnica nas áreas de desenvolvimento
de software, arquitetura de sistemas, banco de dados e engenharia de software,
com foco na construção de soluções práticas e escaláveis.

## 🎯 Áreas de Estudo

- Fundamentos de Programação
- Estrutura de Dados e Algoritmos
- Banco de Dados
- Engenharia de Software
- Desenvolvimento Web
- Arquitetura de Sistemas
- Projetos Integradores

## 🛠 Tecnologias e Ferramentas

Python • JavaScript • SQL • Git • Linux • APIs REST • HTML • CSS

## 📈 Objetivo do Portfólio

Demonstrar evolução prática no desenvolvimento de sistemas,
aplicando conceitos acadêmicos em projetos reais e experimentais.
