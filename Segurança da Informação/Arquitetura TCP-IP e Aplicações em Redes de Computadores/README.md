# Arquitetura TCP/IP e Aplicações em Redes de Computadores

Esta disciplina aborda os fundamentos estruturais da comunicação em redes de computadores, explorando o modelo TCP/IP camada por camada, seus principais protocolos e aplicações. Também cobre endereçamento, roteamento, serviços de rede e protocolos de aplicação utilizados no cotidiano.

---

## Conteúdos abordados

- Introdução às Redes de Computadores
- Modelo TCP/IP — visão geral (camadas)
- Camada Física
- Acesso ao Meio — protocolos de enlace
- Tecnologias Ethernet (10BASE2, 10BASET, FastEthernet, GigabitEthernet)
- Camada de Internet
  - IP
  - ARP / RARP
  - Endereçamento IPv4
  - Sub-redes (CIDR / VLSM)
  - NAT
- Camada de Transporte
  - UDP
  - TCP
  - 3-way Handshake
  - Controle de congestionamento
- Protocolos de Roteamento
- Camada de Aplicação
  - Aplicações cliente-servidor
  - Aplicações P2P
  - Servidores de aplicação
  - DNS
  - DHCP
  - Correio eletrônico (SMTP / POP3 / IMAP)
  - FTP / TFTP
  - HTTP / HTTPS
- Integração prática das aplicações e camadas (LAN, WAN e Nuvem)

---

## Aplicação prática no mercado

Este conteúdo é extremamente aplicado em ambientes reais de infraestrutura e operações de redes, sendo base para:

- administração de redes
- troubleshooting (OSI/TCP-IP → top-down)
- roteamento dinâmico e estático
- configuração de VLANs, NAT, DHCP, DNS
- análise de pacotes com Wireshark
- modelagem de topologias para redes corporativas
