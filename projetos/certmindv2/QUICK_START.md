# 🚀 Guia de Início Rápido - CertMind V2

## ⚡ Começando em 3 Passos

### 1️⃣ Instalar e Executar

```bash
cd projetos/certmindv2
pip install -r requirements.txt
streamlit run app_v2_final.py
```

### 2️⃣ Acesse a Aplicação

- Abra seu navegador em: **http://localhost:8501**

### 3️⃣ Comece a Estudar!

- Escolha entre **Core 1** ou **Core 2**
- O sistema selecionará as melhores questões para você
- Responda e receba feedback detalhado

## 🎓 Dicas de Uso

1. **Estude consistentemente** — 15-30 minutos por dia é melhor que 3h uma vez por semana
2. **Confie no algoritmo** — o sistema sabe quando você deve revisar cada conceito
3. **Leia as explicações** — mesmo quando acertar, reforce o conhecimento
4. **Use o Dashboard** — identifique suas áreas fracas e foque nelas
5. **Mantenha a sequência** — dias consecutivos ajudam a consolidar o hábito

---

## 📊 Entendendo as Métricas

### Taxa de Acerto
- **80%+**: Excelente! Continue assim
- **70-80%**: Bom desempenho
- **60-70%**: Regular, precisa revisar mais
- **<60%**: Foque nos fundamentos

### Nível de Domínio
- **0-40%**: Iniciante - continue praticando
- **40-70%**: Intermediário - no caminho certo
- **70-90%**: Avançado - quase lá!
- **90-100%**: Mestre - conceito dominado! ⭐

### Próxima Revisão
- Calculada automaticamente com base no algoritmo de repetição espaçada (SM-2)
- Quanto melhor seu desempenho, maior o intervalo

---

## ❓ Perguntas Frequentes

**Quantas questões devo fazer por dia?**
Recomendado 10-20, mínimo 5, sem máximo (qualidade > quantidade).

**O que é repetição espaçada?**
Técnica de aprendizado que revisa conceitos em intervalos crescentes para maximizar retenção de longo prazo.

**Devo estudar todos os dias?**
Ideal sim; na prática, 4-5 dias por semana mantém bom progresso.

---

## 🛠️ Solução de Problemas

**Erro ao iniciar:**
```bash
pip install --upgrade -r requirements.txt
```

**Dados corrompidos:**
```bash
python utils/data_migration.py
```

**Resetar progresso:** Dashboard → Opções Avançadas → Resetar Progresso (ação não pode ser desfeita).
